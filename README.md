## How To Use

To clone and run this application, you'll need [Git](https://git-scm.com) and [Node.js](https://nodejs.org/en/download/) (v22+) installed on your computer. From your command line:

```bash
# Clone this repository
$ git clone https://github.com/thomasblaymire/tomblaymire.com

# Go into the repository
$ cd tomblaymire.com

# Install dependencies
$ yarn

# Run the web app
$ yarn dev

# Build the web app
$ yarn build

# Run unit tests
$ yarn test

# Run E2E tests
$ yarn test:e2e

# Run E2E tests with UI
$ yarn test:e2e:ui

# Run ESLint
$ yarn lint

# Type check
$ yarn type-check
```
